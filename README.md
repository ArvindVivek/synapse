# Synapse

Practice League of Legends pro drafts against a sparring opponent, with pick and ban advice that
explains itself, a live win chance, scouting of a sample opponent, and a coach's report at the end.

**Live:** https://synapse-henna-eight.vercel.app · © 2026 Kitchen Labs · Started at the Cloud9 ×
JetBrains hackathon (2026).

## What it does

- **Draft** in the real 20-turn tournament order (bans 3-3, picks 1-2-2-1, bans 2-2, picks 1-2-1)
  as blue or red side. The practice opponent plays its own turns.
- **Formats:** Tournament; Fearless (a series where picked champions are locked for later games);
  Scrim (undo your last move).
- **Advice:** five suggestions every turn with plain reasons (synergy, counters, what your team is
  missing, strength, flex), plus a checklist of magic damage, physical damage, engage and frontline.
- **Win chance** with a readable breakdown: champion strength, teamwork, head-to-head, side.
- **Scouting:** eight fictional sample teams; each player's pool and their likely next pick.
- **Report:** grade, lane-by-lane edges, then (on request) a coach's report written by
  AI, or by code from the same numbers when AI isn't available.

## Data

The original app read pro match data (GRID) from a Supabase database that no longer exists. Synapse
now runs entirely on bundled JSON in `lib/fixtures/` (about 19 KB):

| File | What | Source |
|---|---|---|
| `champions.json` | 70 champions: roles, damage type, engage/frontline/peel tags, flex roles | the original app's champion tables |
| `meta.json` | estimated win rates, 88 synergy pairs, 77 counter pairs | the original app's heuristic tables |
| `teams.json` | 8 fictional teams, 40 players, 247 pool entries | generated by `npm run fixtures` (seeded) |

Draft sessions are saved in the browser (localStorage). There is no database and no account.

## Run it

```bash
npm install
npm run dev            # http://localhost:3187
npm run gate           # kit check, typecheck, lint (0 warnings), unit tests, build, leak check
npm run build && npm run e2e   # Playwright on the production build, phone + desktop
```

`OPENAI_API_KEY` (server only, in `.env.local`) turns on AI-written reports; without it every report
is code-written. See `CLAUDE.md` for the operating manual, `DESIGN.md` for the look, and
`docs/CREDITS.md` for Riot's assets and the fan-project notice.
