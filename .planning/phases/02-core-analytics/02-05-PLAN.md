   - secondary_role VARCHAR(20) (second most games)

   - UNIQUE(player_id, champion_name)

  <name>Task 2: Create player pool computation script</name>

Create a TypeScript script that computes player champion pools:

**Part 1: Player Champion Pools**

1. **Query all picks with player data:**
   ```sql
   SELECT
     cp.player_id,
     cp.champion_name,
     cp.role,
     cp.role_confidence,
     g.blue_team_won,
     cp.team_side,
     s.started_at
   FROM synapse.champion_picks cp
   JOIN synapse.drafts d ON cp.draft_id = d.id
   JOIN synapse.games g ON d.game_id = g.id
   JOIN synapse.series s ON g.series_id = s.id
   WHERE cp.player_id IS NOT NULL
   ORDER BY cp.player_id, cp.champion_name, cp.role
   ```

2. **Aggregate by (player_id, champion_name, role):**
   - Count games_played
   - Count wins
   - Calculate raw_win_rate
   - Apply Bayesian smoothing (prior: 50%, weight: 5 for player pools)
   - Calculate weighted_win_rate using recency weighting (30-day half-life)
   - Average role_confidence across games
   - Track last_played date
   - Calculate days_since_played

3. **Assign comfort_level:**
   ```typescript
   function getComfortLevel(games: number, winRate: number): string {
     if (games >= 10 && winRate >= 0.55) return 'signature'
     if (games >= 5 && winRate >= 0.50) return 'comfort'
     if (games >= 3) return 'occasional'
     return 'rare'
   }
   ```

4. **Upsert to player_champion_pools**

**Part 2: Flex Picks**

1. **Find players with same champion in multiple roles:**
   ```sql
   SELECT player_id, champion_name, role, games_played
   FROM player_champion_pools
   WHERE games_played >= 2
   GROUP BY player_id, champion_name
   HAVING COUNT(DISTINCT role) > 1
   ```

2. **Calculate flexibility score:**
   - Collect roles_played array
   - Identify primary_role (most games) and secondary_role
   - Calculate flexibility_score = 1 - (max_role_games / total_games)
     - Score of 0.5 = perfectly split between 2 roles
     - Score near 0 = one role dominates
   - Set is_true_flex = TRUE if 2+ roles with 3+ games each

3. **Upsert to flex_picks**

4. **Log to analytics_refresh_log**

**Run command:** `npx tsx scripts/analytics/compute-player-pools.ts`
