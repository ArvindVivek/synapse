   - ci_upper DECIMAL(5,4) (Wilson confidence interval upper bound)

   - updated_at TIMESTAMPTZ DEFAULT NOW()

  <action>
Create a TypeScript script that aggregates champion statistics from raw data:

1. **Query recent patches:**
   - Get last 3 distinct patch_version from synapse.series
   - Store as array for filtering

2. **Aggregate champion stats:**
   For each (champion_name, patch_version, role, side) combination:
   - Count games_played from champion_picks
   - Count wins (based on team_side and games.blue_team_won)
   - Apply Bayesian smoothing to win rate
   - Calculate pick rate = games / total_games_in_context
   - Calculate Wilson confidence interval
   - Assign confidence level

3. **Aggregate bans:**
   Count bans per champion from drafts.blue_bans and drafts.red_bans arrays.

4. **Upsert to champion_stats_computed:**
   Use ON CONFLICT (champion_name, patch_version, role, side) DO UPDATE
   to update existing rows.

5. **Log to analytics_refresh_log:**
   Record job_name='champion_stats', status, duration_ms, rows_affected.

**Implementation details:**
- Use @supabase/supabase-js from scripts/etl/node_modules (share dependencies)
- Load .env from scripts/etl/.env.local
- Process side='blue', side='red', and side=NULL (combined) separately
- Filter by role_confidence >= 0.5 to exclude low-confidence role assignments
