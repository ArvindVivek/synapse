<task type="auto">
  <name>Task 2: Create synergy computation script</name>
  <files>scripts/analytics/compute-synergies.ts</files>
  <action>
Create a TypeScript script that computes champion synergies:

1. **Query recent patches:**
   - Get last 3 distinct patch_version from synapse.series

2. **Self-join champion_picks to find pairs:**
   ```sql
   SELECT
     LEAST(p1.champion_name, p2.champion_name) AS champion_a,
     GREATEST(p1.champion_name, p2.champion_name) AS champion_b,
     p1.draft_id,
     d.game_id,
     g.blue_team_won,
     p1.team_side
   FROM synapse.champion_picks p1
   JOIN synapse.champion_picks p2
     ON p1.draft_id = p2.draft_id
     AND p1.team_side = p2.team_side
     AND p1.champion_name < p2.champion_name
   JOIN synapse.drafts d ON p1.draft_id = d.id
   JOIN synapse.games g ON d.game_id = g.id
   JOIN synapse.series s ON g.series_id = s.id
   WHERE s.patch_version IN (recent_patches)
     AND p1.role_confidence >= 0.5
     AND p2.role_confidence >= 0.5
   ```

3. **Aggregate synergy stats:**
   For each (champion_a, champion_b, patch_version):
   - Count games_together
   - Count wins_together (using team_side and blue_team_won)
   - Calculate raw_win_rate
   - Apply Bayesian smoothing (prior: 50% win rate, weight: 10 games)
   - Calculate synergy_delta = smoothed_win_rate - 0.50
   - Calculate Wilson confidence interval
   - Assign confidence level

4. **Minimum threshold:** Only include pairs with games_together >= 5

5. **Upsert to champion_synergies:**
   ON CONFLICT (champion_a, champion_b, patch_version) DO UPDATE

7. **Aggregate archetype_synergies** from champion pairs:
