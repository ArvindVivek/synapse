<task type="auto">
  <name>Task 2: Create matchup computation script</name>
  <files>scripts/analytics/compute-matchups.ts</files>
  <action>
Create a TypeScript script that computes matchup and pick order stats:

**Part 1: Champion Matchups**

1. **Query recent patches** (last 3)

2. **Join picks against opponent in same role:**
   ```sql
   SELECT
     p1.champion_name AS champion,
     p2.champion_name AS opponent,
     p1.role,
     s.patch_version,
     p1.team_side,
     g.blue_team_won
   FROM synapse.champion_picks p1
   JOIN synapse.champion_picks p2
     ON p1.draft_id = p2.draft_id
     AND p1.role = p2.role
     AND p1.team_side != p2.team_side
   JOIN synapse.drafts d ON p1.draft_id = d.id
   JOIN synapse.games g ON d.game_id = g.id
   JOIN synapse.series s ON g.series_id = s.id
   WHERE s.patch_version IN (recent_patches)
     AND p1.role_confidence >= 0.5
     AND p2.role_confidence >= 0.5
   ```

3. **Aggregate matchup stats:**
   For each (champion, opponent, role, patch_version):
   - Count games
   - Count wins for champion
   - Calculate raw_win_rate
   - Apply Bayesian smoothing
   - Calculate matchup_delta = smoothed_win_rate - 0.50
   - Assign confidence level

4. **Minimum threshold:** games >= 3 (lower than synergy because matchups are sparser)

5. **Upsert to champion_matchups**

**Part 2: Pick Order Stats**

1. **Classify pick phases:**
   - early: pick_order IN (1, 2, 3)
   - mid: pick_order IN (4, 5, 6, 7)
   - late: pick_order IN (8, 9, 10)

2. **Calculate blind pick success:**
   For each champion, when picked BEFORE opponent in same role:
   - Compare pick_order of champion vs opponent
   - If champion.pick_order < opponent.pick_order, it's a blind pick
   - Calculate win rate for blind picks

3. **Calculate counter pick success:**
   When picked AFTER opponent (champion.pick_order > opponent.pick_order)

4. **Aggregate by (champion, role, patch_version, pick_phase)**

5. **Upsert to pick_order_stats**

6. **Log to analytics_refresh_log**

**Run command:** `npx tsx scripts/analytics/compute-matchups.ts`

  role: string
  pick_phase: 'early' | 'mid' | 'late'
  blind_pick_success: number
  counter_pick_success: number
  recommendation: 'good_blind_pick' | 'better_late' | 'neutral'
}

/**

export async function getCountersTo(
  champion: string,
  role: string,
  patchVersion: string,
  limit?: number

export async function getCounteredBy(
  champion: string,
  role: string,
  patchVersion: string,

 * Get matchup score between two specific champions

export async function getMatchup(

 * Get pick order recommendation for a champion

export async function getPickOrderRecommendation(

export async function getBestBlindPicks(
