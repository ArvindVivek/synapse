   - id UUID PRIMARY KEY

   - context_type VARCHAR(20) NOT NULL (CHECK: global, team, player)

<task type="auto">
  <name>Task 2: Create ban analytics computation script</name>
  <files>scripts/analytics/compute-ban-analytics.ts</files>
  <action>
Create a TypeScript script that computes ban analytics from raw data:

1. **Query recent patches:**
   - Get last 3 distinct patch_version from synapse.series

2. **Compute global ban analytics:**
   For each champion and patch:
   - COUNT times_banned from drafts.blue_bans and drafts.red_bans (using unnest on TEXT[] arrays)
   - Calculate ban_rate = times_banned / (total_games * 2) (each game has 2 teams banning)
   - Apply Bayesian smoothing (prior: global average ban rate, weight: 10)
   - Assign confidence level based on times_banned
   - Rank champions by ban_rate (1 = most banned)
   - Upsert to ban_analytics with context_type='global', context_id=NULL

3. **Compute team-specific ban analytics:**
   For each team (from series.blue_team_id/red_team_id):
   - Find games where team was playing
   - Count bans made BY that team
   - Aggregate which champions team prefers to ban
   - Upsert to ban_analytics with context_type='team', context_id=team_grid_id

4. **Compute target bans (bans against specific players):**
   For each player:
   - Find games where player's team was opponent
   - Count how often each champion was banned BY the opposing team
   - Cross-reference with player's champion pool (from champion_picks)
   - Mark is_comfort_pick=true if player has played that champion 3+ times
   - Upsert to target_bans

5. **Log to analytics_refresh_log:**
   Record job_name='ban_analytics', status, duration_ms, rows_affected.

**SQL pattern for unnesting ban arrays:**
```sql
SELECT unnest(blue_bans) AS champion_name, 'blue' AS banning_side
FROM synapse.drafts
UNION ALL
SELECT unnest(red_bans) AS champion_name, 'red' AS banning_side
FROM synapse.drafts
```
