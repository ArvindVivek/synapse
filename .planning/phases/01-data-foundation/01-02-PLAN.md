**role-inference.ts:**

```typescript
import { getChampionRolePrior } from './champion-roles.ts';

type Role = 'top' | 'jungle' | 'mid' | 'adc' | 'support';

interface RoleInferenceInput {
  championName: string;
  playerPrimaryRole: Role | null;  // From roster data (may be missing)
  assignedRoles: Role[];           // Already-assigned roles on the team
}

interface RoleInferenceResult {
  role: Role;
  confidence: number;  // 0.0 to 1.0
  reasoning: string;   // For debugging/transparency
}

export function inferRole(input: RoleInferenceInput): RoleInferenceResult
```

**Inference algorithm:**

1. Get champion role priors from champion-roles.ts
2. Filter to available roles (not in assignedRoles)
3. Score each available role:
   - Champion prior weight: 0.5 (how often champion plays this role)
   - Player role weight: 0.3 (if playerPrimaryRole matches, boost score)
   - Constraint bonus: 0.2 (role is available and champion has non-zero prior)
4. Select highest-scoring role
5. Calculate confidence: score / max_possible_score
6. Generate reasoning string: "Jinx -> ADC (conf: 0.95): Champion prior 0.97, player role match"

**Edge cases:**
- Unknown champion: use DEFAULT_ROLE_PRIOR, low confidence
- All roles assigned (shouldn't happen in valid draft): return first available with warning
- Player role unknown: skip player role weight, recalculate max_possible

Create three Supabase Edge Functions that form the staged ETL pipeline.

**etl-tournaments/index.ts:**
Edge Function that fetches LoL tournaments from GRID API:
1. Create Supabase client with service role key
2. Create GridAPIClient with GRID_API_KEY
3. Get already-completed tournament jobs from checkpoints
4. Query GRID for tournaments (filter: gameId='lol', startTimeScheduled > '2024-01-01')
5. For each new tournament:
   - Mark checkpoint as in_progress
   - Upsert tournament to tournaments table
   - Mark checkpoint as completed
6. Return summary: { fetched: N, new: M, skipped: K }

**etl-series/index.ts:**
Edge Function that fetches series for a specific tournament:
1. Accept tournament_id in request body
2. Get completed series checkpoints for this tournament
3. Query GRID for series in tournament
4. For each new series:
   - Mark checkpoint as in_progress
   - Extract: teams, patch_version, winner, timestamps
   - Upsert teams if new (by grid_id)
   - Upsert series with foreign keys
   - Mark checkpoint as completed
5. Return summary

**etl-drafts/index.ts:**
Edge Function that extracts drafts from a specific series:
1. Accept series_id in request body
2. Query GRID seriesState API for games
3. For each game:
   - Create game record
   - Extract bans (blue_bans, red_bans from characterBans)
   - Create draft record
   - For each player:
     - Upsert player if new
     - Use inferRole() to determine role
     - Insert champion_pick with role and confidence
4. Return summary with role inference stats

**scripts/run-etl.ts:**
