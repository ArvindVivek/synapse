Create comprehensive TypeScript type definitions for the draft state machine:

**DraftPhase enum:**
- `ban1` - First ban phase (3 bans per side, turns 1-6)
- `pick1` - First pick phase (3 picks per side, turns 7-12)
- `ban2` - Second ban phase (2 bans per side, turns 13-16)
- `pick2` - Second pick phase (2 picks per side, turns 17-20)

**DraftTurn type:**
```typescript
type DraftTurn = {
  turnNumber: number      // 1-20
  phase: DraftPhase       // Which phase
  side: 'blue' | 'red'    // Whose turn
  action: 'ban' | 'pick'  // What action
}
```

**TeamComposition type:**
```typescript
type TeamComposition = {
  bans: string[]          // Champion names banned
  picks: Array<{
    champion: string
    role: Role | null     // Assigned role (may be null until role assignment)
  }>
}
```

**DraftState interface:**
```typescript
interface DraftState {
  id: string | null                    // Draft session ID
  currentTurn: number                  // 1-20 (0 = not started)
  phase: DraftPhase                    // Current phase
  userSide: 'blue' | 'red'             // Which side user is playing
  blue: TeamComposition                // Blue team state
  red: TeamComposition                 // Red team state
  availableChampions: Set<string>      // Champions not picked/banned
  isComplete: boolean                  // Draft finished
  startedAt: Date | null
  completedAt: Date | null
}
```

**DraftAction type (discriminated union):**
```typescript
type DraftAction =
  | { type: 'BAN'; champion: string }
  | { type: 'PICK'; champion: string; role?: Role }
  | { type: 'UNDO' }
  | { type: 'RESET' }
```

**Role type:**
```typescript
type Role = 'top' | 'jungle' | 'mid' | 'adc' | 'support'
```

Create Zustand store with Immer middleware for immutable draft state management:

**Store interface:**
```typescript
import { create } from 'zustand'
import { immer } from 'zustand/middleware/immer'
import { DraftState, DraftPhase, TeamComposition } from './types'
import { getTurnInfo, getNextTurn, isUserTurn, DRAFT_SEQUENCE } from './sequence'

interface DraftStore extends DraftState {
  // Actions
  initializeDraft: (params: {
    id: string
    userSide: 'blue' | 'red'
    allChampions: string[]
  }) => void

  executeBan: (champion: string) => boolean        // Returns false if invalid
  executePick: (champion: string, role?: Role) => boolean

  undo: () => void                                 // Undo last action
  reset: () => void                                // Reset to initial state

  // Computed/derived
  getCurrentTurnInfo: () => DraftTurn | null
  isMyTurn: () => boolean
  canBan: (champion: string) => boolean
  canPick: (champion: string) => boolean
  getTeamComposition: (side: 'blue' | 'red') => TeamComposition
}
```

**Initial state factory:**
```typescript
const createInitialState = (): DraftState => ({
  id: null,
  currentTurn: 0,
  phase: 'ban1',
  userSide: 'blue',
  blue: { bans: [], picks: [] },
  red: { bans: [], picks: [] },
  availableChampions: new Set(),
  isComplete: false,
  startedAt: null,
  completedAt: null,
})
```

**Key behaviors:**
1. `initializeDraft` sets id, userSide, populates availableChampions, sets currentTurn to 1, startedAt to now
2. `executeBan` validates it's a ban turn, champion is available, then adds to correct team's bans, removes from available, advances turn
3. `executePick` validates it's a pick turn, champion is available, then adds to correct team's picks, removes from available, advances turn
4. `undo` reverts the last action by restoring the champion to available and removing from bans/picks, decrements turn
5. Use Immer so mutations look direct but are actually immutable

**Important:** Store availableChampions as Set<string> but Immer handles Set mutations. Use `draft.availableChampions.delete(champion)` syntax.
